## Princípios aplicados

| Princípio | Como reflete no sitemap |
|-----------|------------------------|
| **Profundidade controlada** | Máx. 3 cliques do topo ao conteúdo-fim |
| **Agrupamento por tarefa** | "Oportunidades" agrupa editais + programas + trilhas (tudo = captar recurso) |
| **Filtros antes de listas** | Mapas, calendários, editais sempre com facetas |
| **Perfil > hierarquia** | Área logada adapta ao papel, não ao órgão |
| **Conteúdo como produto** | Cases, guias, templates têm dono, versão, validade |
| **Onboarding contínuo** | CTA leva a fluxo, não a formulário estático |
